# Security

## Reporting a problem

Please report security problems privately, using GitHub's private vulnerability reporting: open the **Security** tab of this repository and click **Report a vulnerability**. Please don't open a public issue for a security problem.

Include what you found, how to reproduce it, and what someone could do with it. I'll reply as soon as I can.

## What's in scope

- The code in this repository: the Worker and its API, sign-in checks, roles, the app, and the GitHub Actions workflows.
- Anything that would let someone reach a family's data without being allowed through Cloudflare Access and the app's own user list.

Each family runs and looks after its own copy. Problems with a particular family's Cloudflare account or settings are for that family to fix.
